# 纯稚学知识图谱

以春知网「纯稚」CP 同人写作为样本的文献计量式知识图谱。**单文件离线运行**，下载 `index.html` 后双击即可打开，无外部依赖、无需服务器、无需联网。

## 内容

- 913 个节点 / 1298 条关系：499 篇二创分析、141 个二创概念、261 部理论原典、12 处原始语料
- 四类节点、四种关系：引用／首发／借用／取材
- 四个视图：
  - **发展历程**（默认，按快照日逐波生长，可播放／拖动时间轴）
  - **引文总览**（全图 ＋ 五层分环 ＋ 学科筛选）
  - **语料总览**（12 处原始语料各自的取材网络）
  - **研究空白**（原始语料 × 学科矩阵，空格可生成征稿启事）
- 全站检索：右上角放大镜 → 输入概念／原典／语料／标题／作者／正文片段 → 回车，结果按四类分组列在右栏
